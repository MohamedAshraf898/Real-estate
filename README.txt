Belgrade Arbor — local preview (reference copy, do not publish)

1. Unzip this folder anywhere.
2. Open Terminal in the folder and run:
   python3 serve.py
3. Open http://localhost:8080/en in your browser.

Pages: /en, /en/3d, /en/residences, /en/residences/a-1-01, /en/business,
/en/retail-spaces, /en/about-the-investor, /en/contact
Stop the server with Ctrl+C. Needs Python 3 (built into macOS).
